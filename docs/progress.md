# 项目进度

最后更新：2026-09-09

## 项目定位

轻量级商品追踪应用：通过爬虫采集 Bilibili 会员购转售商品数据，保存到 SQLite，并由 FastAPI 提供查询接口，Vue 前端负责展示和交互。

## 已完成

### 基础与工程

- Git 仓库初始化并完成首个提交。
- 建立 Python 虚拟环境和依赖清单 `requirements.txt`。
- 根目录 `.gitignore` 已排除 `.venv`、`frontend/node_modules`、前端构建产物和 Python 缓存。
- 补充运行、爬虫参数和 API 文档。

### 爬虫

- 获取首页概览信息。
- 获取商品分类、IP 分区和排序方式。
- 按页抓取商品列表，支持分类、IP、排序和页数筛选。
- 支持全量抓取、多排序去重和动态停止策略。
- 支持请求重试、限流等待、Session 和 User-Agent 管理。
- 支持商品详情抓取。
- 支持价格趋势分析和价格异动检测。
- 支持 JSON、CSV 和异动 CSV 导出。

### 数据库

- 默认数据库统一为 `data/products.db`。
- 已建立商品主表、价格快照表和抓取批次表。
- 已建立筛选维度和首页快照表。
- 已建立商品详情、成交记录和价格走势点表。
- 已建立收藏表。
- 爬虫会保存首页/筛选数据、商品列表、价格快照及可选详情数据。
- `crawl_runs.actual_pages` 已接入实际抓取页数统计。

### 后端

- FastAPI 应用入口：`backend/main.py`。
- 已按 API、Service、Repository、Database 分层。
- 已提供健康检查、商品、价格历史、抓取记录查询接口。
- 已提供商品详情、成交记录和价格走势接口。
- 已提供分类、IP、排序和首页快照接口。
- 已提供收藏查询、收藏和取消收藏接口。
- 已提供定时爬取任务的创建、查询、修改、启停、立即触发和删除接口。
- 已支持定时任务配置持久化、后端启动恢复和最近一次执行状态记录。
- 已启用 Swagger 和 ReDoc。

### 前端

- 首页已完成商品列表展示、分页和骨架屏/空态/错误态。
- 已支持分类筛选、排序切换（默认/折扣/价格）和关键词搜索。
- 已支持商品详情抽屉，展示价格历史趋势图和成交记录趋势图。
- 已支持深浅色主题切换，主题变量集中在 `frontend/src/styles/theme.css`，通过 `frontend/src/composables/useTheme.js` 统一管理并在首屏前应用，不再出现切页闪白。
- 后台页面已完成即时任务表单、任务状态轮询与实时输出，以及定时任务的创建、编辑、启停、立即触发和删除。
- 全站视觉严格遵循 `frontend/DESIGN.md`：语义颜色/字号 token、单一 elevation 层级、统一的 hover/focus/disabled/loading/empty/error 状态。
- 前端已通过 Vite 构建（`npm run build`），产物输出到 `frontend/dist/`。
