# CLAUDE.md

Project instructions for this repository live in `AGENTS.md` at the repository root. That file is
the single source of truth — architecture, frontend/backend boundaries, verification rules, and
the pointer to `frontend/DESIGN.md` for all UI work.

The import sits on the first line on purpose: imports at the top of a memory file are
re-evaluated most reliably, including across `/compact`.

Do not duplicate `AGENTS.md` content here; edit `AGENTS.md` instead.
